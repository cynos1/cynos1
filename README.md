## 🔬 Doctoral Research

### SafeBERT: Governance-Oriented Evaluation of Bias Detection Systems Under Synthetic Supervision

My doctoral research examines what happens when compact bias-detection models learn from **synthetically generated data and multi-LLM supervision**.

The central question is:

> When a compact bias-detection model is distilled from a multi-LLM ensemble, does it amplify demographic disparities beyond those already present in its teacher models?

The study evaluates three independently generated SafeBERT instances across:

- Gender
- Race
- Age
- Religion
- Socioeconomic status
- Political bias
- Cultural bias
- No Bias

My current work investigates:

- synthetic supervision and teacher disagreement
- demographic false-positive disparities
- teacher-to-student behavior transfer
- distribution shift and external generalization
- decision-level divergence hidden by aggregate metrics
- false-positive auditing across external benchmarks
- governance implications for compact AI classifiers

A major finding so far is that similar aggregate error rates can hide substantial differences in **which individual examples models classify incorrectly**.

## 🤖 Current AI Agent Work

### Devil's Advocate

An autonomous options-trading agent that uses one AI model to challenge another before deterministic code determines what can actually execute.

**Core principle:**

> Models make judgments. Code controls authority.

The system combines:

- adversarial multi-agent reasoning
- deterministic risk gates
- Alpaca Trading API
- Alpaca MCP Server
- Alpaca CLI
- GitHub Actions automation
- auditable decision logs
